# Hermes 3D Changelog

## 0.1.0 — Initial release

- **Agent Swarm** — living constellation of 6 Hermes agents (CTO, PM, Dev, QA, Security, Ops) orbiting a pulsing core, each with distinct geometry and role color. Bloom post-processing, sparkle particles, orbit rings.
- **EXO Cluster** — 3D topology of the distributed inference cluster. Spine node (Mac Mini) at center with 3 worker peers connected by glowing data lines. Floating, spinning, pulsing animations.
- **Project Architecture** — monorepo structure as orbiting modules. Root module at center, 4 orbital rings representing package layers (core, renderers, adapters, tools).
- Scene selector bar with glass-morphism styling
- OrbitControls with auto-rotate on all scenes
