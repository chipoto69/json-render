# Hermes TUI Changelog

## 0.1.0 — Initial release

- Terminal dashboard rendering Hermes agent swarm state
- Live kanban board view via `get_kanban_board` tool
- Agent status panel with color-coded Badges per role
- EXO cluster topology visualization
- Cron schedule table
- Project context (repo, branch, recent commits)
- Auto-refresh with `r` key, quit with `q`
- AI-generated JSON specs using standard Ink components
